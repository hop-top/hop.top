# hop.top

Ecosystem hub — marketing site, edge router, Go vanity imports

## Install

```sh
npm install -g hop.top
```

## Usage

```sh
hop.top --help
hop.top --version
```

### Output formats

```sh
hop.top --format json
hop.top --format yaml
```

## Development

Prerequisites: Node.js 22+, [Task](https://taskfile.dev)

```sh
task setup    # install deps
task check    # lint + test
task build    # compile TypeScript
```
