# Installing hop.top

## From Source

```sh
git clone github.com/hop-top/hop.top
cd hop.top
task build
```

## Go

```sh
go install github.com/hop-top/hop.top@latest
```

## npm

```sh
npm install -g hop.top
```

## pip

```sh
pip install hop.top
```

## Homebrew

```sh
brew install hop.top
```

## Verify Installation

```sh
hop.top --version
```

## System Requirements

- Go 1.22+ (for Go builds)
- Node.js 20+ (for TypeScript builds)
- Python 3.11+ (for Python builds)
